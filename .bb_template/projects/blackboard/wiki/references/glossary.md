# 术语

| 术语 | 含义 |
| --- | --- |
| Blackboard | 多项目工作台，承载 ticket / inbox / wiki |
| Ticket | 项目内结构化任务单，存于 `tickets/<id>-<slug>.md` |
| Inbox | 项目级 handoff 笔记，存于 `inbox/YYYY-MM-DD-<source>-<topic>.md` |
| Wiki | 项目级知识沉淀，存于 `wiki/`，支持任意深度子目录 |
| Lane | 看板泳道，声明于 `__project__.json#lanes` |
