## 前置条件

- Blackboard Web 前端已在 http://127.0.0.1:8060/ 运行
- 你具备 Computer Use 能力，可以读取当前应用状态、操作本机浏览器或模拟器、截屏并检查视觉表现

## 任务

使用 Computer Use 打开或切换到一个可用浏览器（优先 Chrome，其次 Safari），访问 http://127.0.0.1:8060/，对以下场景逐一截屏验证。

必须实际调用 Computer Use 工具完成 UI 操作和截屏。不要用 shell、curl、Playwright、browser-use 或浏览器内部自动化替代视觉验收。

### 1. 暗色模式检查

1. 打开页面，点击主题切换按钮（通常在顶栏或设置中），切换到 Dark Mode
2. 截屏以下页面，检查是否有视觉异常：
   - Sidebar 导航
   - Board 看板视图
   - Ticket 详情面板
   - Graph 依赖图
   - Wiki 页面
3. 异常标准：
   - 白色闪块（组件未适配暗色背景）
   - 文字不可读（深色文字在深色背景上）
   - 边框消失或过于突兀
   - 图标/按钮对比度不足

### 2. 国际化检查

1. 切换语言到中文，截屏主要页面
2. 切换语言到英文，截屏同样的页面
3. 检查：
   - 是否有未翻译的硬编码文本（中文环境出现英文，或反之）
   - 文本是否溢出按钮/卡片/工具栏
   - 切换语言后布局是否错位

### 3. 报告

输出一份简洁的验收报告：

```markdown
## 冒烟测试结果

### 通过
- [ ] 暗色模式 Sidebar
- [ ] 暗色模式 Board
- [ ] ...

### 失败
- [ ] <页面> — <问题描述>

### 建议
- <需要人工处理的问题>
```

## 约束

- 只做视觉验收，不修改代码
- 使用 Computer Use 读取应用状态、点击、输入、滚动和截屏
- 每个页面最多等待 5 秒加载
- 如果页面打不开，报告 "前端服务未运行" 并停止
- 如果 Computer Use 被系统权限或安全策略阻止，报告 "Computer Use 不可用" 并写明阻塞点
